
# ☁️ Azure Administrator 30-Day Challenge

Welcome to my Azure Administrator learning journey.

This repository documents my hands-on experience learning Microsoft Azure, building cloud infrastructure, and preparing for the **AZ-104: Microsoft Azure Administrator** certification.

The goal is simple:

✅ Learn Azure Administration  
✅ Build real-world cloud projects  
✅ Develop job-ready skills  
✅ Document everything publicly  
✅ Become employable as an Azure Administrator / Cloud Support Engineer

---

# 🎯 Objectives

By the end of this challenge I will be able to:

- Manage Azure resources
- Configure Microsoft Entra ID
- Implement Role-Based Access Control (RBAC)
- Deploy and manage Virtual Machines
- Design Azure networking solutions
- Configure monitoring and alerting
- Implement backup and recovery solutions
- Automate deployments using Azure CLI, PowerShell, ARM, and Bicep
